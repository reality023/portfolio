
### 프로젝트 개요 및 배경
- 이용자가 **정면, 측면, 후면 체형 사진**을 제출하면 간단한 체형 분석 결과와 함께, 분석에 맞는 맞춤 운동 영상을 **하루 1분짜리 영상 3개씩** 제공하는 크로스플랫폼 헬스케어 서비스입니다.
- 기획 1명, UI 디자인 1명과 협업하여 Flutter 클라이언트(iOS/Android), 간이 관리자 페이지, Supabase 및 FastAPI 관리자 백엔드, Docker 기반 AWS EC2 배포 및 개발/운영 환경 분리까지 전반적인 개발과 인프라 구축을 완주했습니다.
- 작업 기간이 한정되어 있어, 관리자 페이지는 앱 서비스 제공에 필요한 최소한의 기능만 개발하였습니다.

---

### 주요 개발 내용

#### 1. Flutter 기반 iOS/Android 동시 개발 및 간이 관리자 웹 구현
- Flutter를 활용해 단일 코드베이스로 iOS와 Android 양대 플랫폼 모바일 앱을 동시 개발했습니다.
- 사용자의 정면·측면·후면 사진 촬영 및 업로드 플로우, 체형 분석 결과 화면, 일일 1분 맞춤 운동 영상 3편을 시청할 수 있는 직관적인 UI를 구현했습니다.
- 서비스 운영에 필요한 핵심 관리 기능만 선별하여 별도 관리자 웹 페이지를 구축했습니다.


#### 2. Supabase + FastAPI (Supabase Admin SDK) 하이브리드 백엔드
- 모바일 앱의 메인 데이터베이스와 인증(Auth), 기본 데이터 처리는 **Supabase**를 활용하여 빠르고 안정적으로 구축했습니다.
- 관리자 페이지의 유연하고 정밀한 비즈니스 로직 제어를 위해 **FastAPI** 기반 전용 백엔드를 구축하고, **Supabase Admin SDK**를 연동하여 안전하고 유연한 관리자 API를 구현했습니다.

#### 3. Docker 컨테이너화 및 AWS EC2 배포
- FastAPI 관리자 백엔드와 관리자 웹 페이지를 각각 **Docker 컨테이너**로 패키징했습니다.
- AWS EC2 프리티어 인스턴스를 활용하여 컨테이너 환경으로 배포를 진행함으로써, 환경에 구애받지 않는 안정적인 호스팅 환경을 구축했습니다.

#### 4. 개발 / 운영 환경 분리 및 Flutter 빌드 분기
- 클라우드 비용을 절감하고 빠른 기능 테스트를 진행하기 위해 **개발 서버는 로컬 PC 환경에 세팅**했습니다.
- Flutter 앱의 빌드를 **개발(Dev) 빌드**와 **운영(Prod) 빌드**로 분리하여, 개발 빌드는 로컬 PC의 개발 서버로 연결되어 실시간 디버깅이 가능하고, 운영 빌드는 AWS EC2 서버와 안전하게 통신하도록 환경을 분리했습니다.
