### 📌 프로젝트 개요 및 배경
- 제약 CSO(영업대행사) 업계의 복잡한 전자계약 체결과 대규모 판매 실적 데이터를 정확하게 정산·관리하는 B2B 엔터프라이즈 솔루션입니다.
- 레거시 환경을 개선하기 위해 On-Premise 및 NCP(Naver Cloud Platform) 인프라 세팅부터 FastAPI 백엔드, Next.js 프론트엔드까지 전 과정을 주도했습니다.

---

### 🛠️ 주요 개발 및 아키텍처 개선

#### 1. 기존 코드베이스 유지보수 및 NCP Cloud 기반 인프라 구축
- 기존에 외주로 만들어진 코드베이스를 받아서, 기능을 파악하고 실 서비스가 가능하도록 개선 및 유지보수 작업을 진행하였습니다. 또한 사내 PC에 개발서버, NCP에 운영서버를 세팅하였습니다.

#### 2. 전자계약 관리 / AI 실적 관리 기능 개발
- 전자계약 관리 플랫폼(eformsign)의 API를 연동하여 전자계약 문서 서명, 저장, 다운과 같은 신규 기능을 개발하였습니다.
- 실적 이미지를 업로드하면 AI 서버를 거쳐 추출된 텍스트를 기반으로 실적 데이터를 만드는 기능을 개발하였습니다. (실제 AI 기능은 AI 개발자들이 작업)

#### 3. NCP Object Storage 기반 저장소 아키텍처 개편
- 기존 로컬 서버 디스크에 계약서 및 정산 증빙 파일을 저장하던 구조는 파일 누적 시 서버 용량 관리 및 다중 서버 확장(스케일아웃)에 한계가 있었습니다.
- 서버 스토리지 의존성을 분리하기 위해 NCP Object Storage 기반으로 아키텍처를 개편했습니다. 또한 비인가 접근을 방지하고 보안을 강화하기 위해, 사용자 권한 검증을 거친 인증된 요청에 대해서만 안전하게 증빙 파일을 다운로드할 수 있도록 API 보안 및 파일 관리 체계를 구축했습니다.

#### 4. Docker 컨테이너화 & GitHub Actions CI/CD 파이프라인
- 개발-스테이징-운영 환경의 불일치를 해소하기 위해 도커 컨테이너 환경을 구축했습니다.
- GitHub Actions를 연동하여 코드 푸시 시 린트 및 자동 배포가 이루어지는 배포 워크플로우를 완성했습니다.
