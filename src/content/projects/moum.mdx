### 프로젝트 개요 및 배경
- 카카오톡 '나에게 보내기'나 메모장에 산발적으로 임시 저장하던 링크와 메모들이 정작 필요할 때 찾기 어려워 유실되는 일상 속 불편함에서 착안한 **정보 아카이빙 및 큐레이션 웹 서비스**입니다.
- 링크와 메모를 '모음(보드/폴더)'과 '조각(아이템)' 단위로 분류하고, 언제 어디서든 빠르게 추가·보관·공유할 수 있도록 개발했습니다.
- 항해99 최종 실전 프로젝트로 6주간 진행되었으며, 프론트엔드 2명, 백엔드 3명, 디자이너 1명과 협업하여 개발했습니다.
- 배포 후 유저 피드백(1차 설문 73명)을 수렴하여 주요 불편 사항 6가지를 개선하였고, **서비스 만족도를 52.3%에서 90.0%로 개선(+37.7%p)**했습니다.

### 주요 개발 내용

#### 1. 빠른 개발 속도와 협업을 고려한 기술 스택 선정
- 프론트엔드 인원(2명)이 백엔드(3명)에 비해 적은 상황에서 정해진 기간 내 안정적으로 구현하기 위해 **React + TypeScript + React Query + Recoil** 스택을 선정했습니다.
- **React Query**: 서버 데이터 캐싱과 로딩/에러 상태 관리를 단순화하여 불필요한 API 재호출을 방지하고 상태 관리 코드를 간소화했습니다.
- **Recoil**: 플로팅 바 활성화 여부, 가이드 모달 표시 등 클라이언트 전역 UI 상태를 가볍게 분리하여 관리했습니다.
- **Tailwind CSS & Styled Components**: 공통 레이아웃은 Tailwind CSS 유틸리티로 빠르게 작업하고, 세부 조작이 필요한 인터랙션 컴포넌트는 Styled Components를 병행하여 작업 효율을 높였습니다.

#### 2. 아카이빙 및 큐레이션 기능 구현
- **하단 플로팅 바 퀵 조각 등록**: 어느 페이지에서든 화면 하단 플로팅 박스를 통해 손쉽게 메모와 링크를 작성하고 원하는 모음에 분류 저장할 수 있도록 구현했습니다.
- **모음 & 조각 CRUD 및 검색·정렬**: 모음과 조각의 생성·수정·삭제, 키워드 검색, 태그 필터링 및 사용자가 직접 순서를 변경할 수 있는 커스텀 정렬 기능을 구현했습니다.
- **소셜 큐레이션**: 다른 유저의 모음을 내 보관함으로 스크랩하거나 관심 있는 유저를 팔로우할 수 있는 기능을 구현했습니다.

#### 3. Axios 인터셉터 기반 JWT 토큰 재발급 및 로그인 연동
- **토큰 자동 갱신**: Axios 응답 인터셉터를 설정하여 `401 Unauthorized` 에러 발생 시 Refresh Token으로 새 Access Token을 재발급받고, 직전 요청을 다시 전송하도록 처리했습니다.
- **인증 플로우 연동**: Google OAuth 2.0 소셜 로그인 및 이메일 인증번호 발송/확인을 통한 자체 회원가입 기능을 연동했습니다.

### 유저 피드백 기반 6대 사용성 개선 내용

> **[TROUBLESHOOTING & UX ITERATION RECORD]**
>
> 1차 배포 후 3일간 73명의 유저 응답을 바탕으로 서비스 만족도가 52.3%로 집계되었습니다.
> 수집된 의견을 분석하여 사용자가 겪은 주요 불편 사항 6가지를 정리하고 개선 작업을 진행했습니다.
>
> **1. 서비스 사용법 및 온보딩 가이드 부족**  
> **이슈**: 모음, 조각, 스크랩 등 서비스 기본 개념과 사용법을 알기 어렵다는 피드백.  
> **해결**: 첫 진입 시 서비스 사용법을 단계별로 안내하는 온보딩 팝업을 추가하여 진입 장벽을 낮췄습니다.
>
> **2. 조각 생성 진입 장벽**  
> **이슈**: 모음 생성에 비해 모음 안에 들어갈 '조각'을 추가하는 버튼 위치를 찾기 어렵다는 피드백.  
> **해결**: 모음 상세 화면 진입 시 직관적으로 알아볼 수 있는 `+` 조각 추가 버튼을 화면 상단에 명확하게 배치했습니다.
>
> **3. 소셜 로그인 시인성 부족**  
> **이슈**: 일반 회원가입 폼이 먼저 눈에 띄어 구글 소셜 로그인 기능이 있는지 인지하기 어렵다는 피드백.  
> **해결**: 구글 소셜 로그인 버튼의 컬러 대비를 강화하고 로그인 영역 상단으로 시각적 배치를 조정했습니다.
>
> **4. 긴 콘텐츠 탐색 시 상단 이동 피로도**  
> **이슈**: 피드와 랜딩 페이지를 스크롤한 뒤 다시 최상단으로 이동하기 번거롭다는 피드백.  
> **해결**: 스크롤 시 나타나는 플로팅 Top Scroll 버튼을 추가하여 최상단으로 한 번에 이동할 수 있도록 지원했습니다.
>
> **5. 반복적인 확인 다이얼로그(Dialog) 피로도**  
> **이슈**: 조각 생성, 인증번호 입력 등 매 동작마다 확인 버튼을 눌러야 팝업이 닫혀 번거롭다는 피드백.  
> **해결**: 확인을 강제하는 다이얼로그 대신 수초 후 자동으로 사라지는 토스트(Toast) 메시지로 교체하여 연속 사용성을 개선했습니다.
>
> **6. 로그인 직후의 랜딩 페이지 불일치**  
> **이슈**: 로그인 완료 후에도 홍보용 랜딩 페이지에 머물러 매번 '나의 모음' 메뉴를 직접 클릭해야 한다는 피드백.  
> **해결**: 로그인 성공 즉시 메인 작업 공간인 '나의 모음' 화면으로 바로 이동하도록 라우팅 흐름을 변경했습니다.
>
> **결과**: 개선 사항 반영 후 진행된 2차 설문조사(20명 응답)에서 **사용자 만족도 90.0%(+37.7%p 상승)** 결과를 얻었습니다.
